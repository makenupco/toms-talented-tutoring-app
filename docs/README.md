# Docs folder for GitHub Pages

This folder contains a minimal static site (index.html) so GitHub Pages can serve this repository using the `docs/` folder on the default branch.

If you'd like automated builds that compile the Expo/React Native web output and publish it to Pages, tell me whether you'd prefer the site published from `docs/` on `main` or from a `gh-pages` branch and I will add a workflow to build and deploy.
